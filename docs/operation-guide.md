# Telegram 影视 Bot 操作说明

## 1. 文档信息

| 项目         | 内容                                                    |
| ------------ | ------------------------------------------------------- |
| 文档用途     | 用户及管理员日常操作手册                                |
| 适用产品     | Telegram Bot、Mini App、内容管理台                      |
| 文档版本     | 1.0                                                     |
| 更新日期     | 2026-09-02                                              |
| 视频播放方式 | Bot 私聊发送，Telegram 原生播放器播放                   |
| 媒体存储方式 | Telegram 私有存储频道保存媒体，业务服务保存索引与元数据 |

本文档不包含 Bot Token、服务器密码、数据库凭据、私有频道邀请链接等敏感配置。

## 2. 角色与入口

### 2.1 普通用户与会员

用户在 Telegram 中进入 Bot：

- `/start`：启动 Bot，并显示内容库和使用说明入口。
- `/help`：查看用户操作说明。
- `打开内容库`：进入 Mini App。

普通用户可以浏览公开内容，也可以看到会员作品的安全基础资料、独立公开封面和会员标识，但不能读取会员目录、内容单元或媒体文件。会员有效时，可以浏览全部已发布内容。

### 2.2 管理员

有效管理员在 Bot 中使用：

- `/admin`：打开内容管理台。
- `/help`：除用户说明外，还会显示管理员说明。

管理台仅支持从 Telegram 中的管理员入口打开。直接使用普通浏览器访问不会建立管理会话。

## 3. 用户快速开始

1. 打开 Bot，发送 `/start`。
2. 点击 `打开内容库` 进入 Mini App。
3. 在首页查看推荐、偏好排行、最近更新、继续阅读和最近发送。
4. 点击作品封面进入作品详情。
5. 图片作品直接选择目录阅读；影视内容选择具体视频后请求发送。
6. 视频发送成功后返回 Bot 私聊，使用 Telegram 原生播放器观看。

## 4. 浏览、分类与搜索

### 4.1 首页

首页可能显示：

- 为你推荐和热门新作。
- 根据用户行为计算的偏好排行。
- 最近更新作品。
- 最近一次阅读及继续阅读入口。
- 最近一次视频发送及发送状态。

推荐与排行会参考浏览、点击、收藏、阅读、视频发送、类型和标签偏好。新用户主要看到整体热度和最近更新。

### 4.2 分类

底部点击 `分类`，可按以下主类型筛选：

- 影视
- 漫画
- 图集
- 写真

作品详情中的目录按实际已发布内容动态生成。当前作品没有漫画、写真、剧照或花絮时，对应目录不会显示。

### 4.3 搜索

在分类页的搜索框中输入片名、别名、地区或标签。没有结果时，可缩短关键词、清空类型筛选后重试。

### 4.4 收藏

在作品详情中点击心形按钮即可收藏或取消收藏。底部点击 `收藏` 可查看已收藏的作品。

## 5. 图集与写真浏览

1. 打开作品详情。
2. 选择图集或写真目录中的图片集。
3. 点击图片进入查看模式。
4. 左右滑动切换图片，双指缩放查看细节。
5. 使用缩略图定位其他图片。
6. 退出后系统保存最近查看位置，之后可从阅读记录继续。

图片加载失败时，可对单张图片重试，不影响继续查看其他页面。Mini App 提供的是经过权限校验的浏览版本，不提供图片源文件下载。

## 6. 漫画阅读

1. 打开漫画作品并选择章节。
2. 根据阅读习惯选择连续滚动或单页阅读。
3. 在支持的布局中选择单页或双页，以及从左到右或从右到左。
4. 阅读位置和布局偏好会自动保存。
5. 从首页的继续阅读或 `我的 > 阅读记录` 恢复进度。

漫画作品只包含漫画章节和图片，不包含视频目录。

## 7. 视频发送与播放

1. 打开影视作品，或打开写真作品的拍摄花絮目录。
2. 选择电影、剧集、短视频或花絮视频。
3. 点击发送到 Telegram 的操作按钮。
4. Mini App 显示排队、发送中、已发送或发送未完成状态。
5. 返回 Bot 私聊，打开收到的视频消息。
6. 使用 Telegram 原生播放器播放。

同一内容存在多个可用视频版本时，系统默认发送画面像素最高的版本。视频消息启用 Telegram 内容保护，以限制官方客户端中的转发和保存。消息发送成功后不会自动删除。

系统记录的是用户请求和发送结果，不等同于精确播放进度，也不能判断用户是否看完视频。

## 8. 会员权限

### 8.1 普通用户

- 可以查看公开作品和公开内容。
- 可以看到会员作品的安全基础资料、独立公开封面、会员标识和开通入口。
- 不能看到完全锁定作品的会员目录、单元数量或媒体地址。
- 不能请求发送会员视频，也不能读取会员图片或漫画页。

### 8.2 有效会员

- 可以浏览所有已发布作品、目录、内容单元和文件。
- 会员到期后立即恢复为普通用户权限。
- 会员到期不会自动删除此前已经发送成功的视频消息。

### 8.3 会员总开关

管理员关闭会员权限总开关时，全部已发布内容按公开权限计算；重新开启后，系统恢复作品、目录和内容单元原有的会员规则。

## 9. 用户常见问题

### 9.1 提示“请先启动 Bot”

返回 Bot 私聊发送 `/start`，然后重新打开原作品并再次请求发送。

### 9.2 Bot 被屏蔽或无法发送

解除对 Bot 的屏蔽，重新发送 `/start` 后重试。实际能否发送以 Telegram 返回结果为准。

### 9.3 视频长时间排队

打开 `我的 > 最近发送` 查看状态。网络或 Telegram 临时繁忙时稍后重试，避免连续重复点击。

### 9.4 Mini App 页面未正常载入

关闭 Mini App 后从 Bot 重新打开，并确认 Telegram 和网络连接正常。

### 9.5 找不到某个目录

仅实际存在、已发布且当前账号有权访问的目录会显示。空目录、草稿目录、已下架目录及无权访问的会员目录不会出现。

## 10. 管理员内容发布总流程

按以下顺序完成一次标准发布：

1. 在管理台新建作品草稿。
2. 保存作品资料并创建目录。
3. 在目录中创建内容单元。
4. 将媒体发送到 Telegram 私有存储频道。
5. 在管理台 `待入库` 中关联作品或内容单元。
6. 在作品编排中核对媒体并设为 `可用`。
7. 将需要展示的目录设为 `已发布`。
8. 将需要展示的内容单元设为 `已发布`。
9. 确认作品已设置独立公开封面。
10. 点击 `审核并发布`。
11. 到用户端检查目录、图片或视频发送结果。
12. 到审计日志确认发布记录和请求追踪号。

本项目采用单管理员审核与发布，不需要第二名管理员会签。

## 11. 新建作品与资料维护

1. 进入管理台 `作品`。
2. 点击 `新建作品`。
3. 填写作品名称。
4. 选择主类型：影视、漫画、图集或写真。
5. 选择访问级别：公开、会员或继承。
6. 按需填写别名、地区、年份、标签、演员或主体、作者和简介。
7. 点击 `保存资料`，建立作品草稿。

除作品名称和结构所需字段外，地区、年份、演员、作者等扩展资料均可留空，用户端统一显示为未知。内容单元创建后，不应随意修改作品主类型；需要改变时应先核对现有目录与单元是否仍然符合类型规则。

## 12. 目录与内容单元规则

### 12.1 影视

- 允许目录：播放、剧集、剧照。
- 允许单元：电影、剧集、短视频、图片集。
- 剧照使用图片集，视频使用电影、剧集或短视频单元。

### 12.2 漫画

- 允许目录：漫画目录。
- 允许单元：漫画章节。
- 不关联视频单元或视频媒体。

### 12.3 图集

- 允许目录：图集。
- 允许单元：图片集。

### 12.4 写真

- 允许目录：写真、图集、拍摄花絮。
- 允许单元：写真集、图片集、花絮视频。

目录及内容单元都有独立发布状态。只有已发布目录中的已发布单元才可能出现在用户端。

## 13. 视频上传与入库

### 13.1 上传前检查

建议视频预先符合：

- MP4 容器。
- H.264/AVC 视频编码。
- AAC-LC 音频编码。
- `yuv420p` 像素格式。
- fast-start。
- 正确的时长、宽高和缩略图。
- 作为 Telegram 视频消息上传，不作为普通文档上传。
- 单文件不超过当前 Telegram Premium 4GB 上限。

VPS 不负责实时转码。格式不兼容的视频应在上传前处理完成。

### 13.2 入库步骤

1. 将视频直接发送到已配置的私有存储频道。
2. 等待 Bot 创建待入库记录。
3. 打开管理台 `待入库`。
4. 点击关联，选择目标作品和视频内容单元。
5. 填写媒体角色，确认展示范围为受保护内容。
6. 设置排序序号并确认关联。
7. 回到作品编排，核对视频元数据后设为 `可用`。

同一单元可以关联多个视频版本。系统按分辨率选择默认版本；不要通过覆盖旧消息的方式替换已入库版本。

## 14. 图片准备、上传与版本关联

### 14.1 图片版本

同一逻辑图片可包含：

- `source`：源文件，仅用于受控管理和归档，不向用户下发。
- `browse`：Mini App 放大查看使用的浏览版本。
- `thumbnail`：列表、封面或快速首屏使用的缩略图。

浏览版本应在管理员本地预先生成，并满足 Telegram 图片限制：最大 10MB、宽高之和不超过 10000、宽高比不超过 20。源文件超过 Bot API 云端获取上限时，必须在上传前生成浏览版本，VPS 不会下载源文件再转换。

### 14.2 上传与关联

管理台不直接接收媒体文件。为保持 Telegram 文件 ID 复用和 4GB 视频链路，必须先使用 Telegram 客户端上传到私有存储频道；Bot 只登记频道消息中的文件 ID 和元数据，VPS 不保存完整媒体文件。

1. 按需要准备 source、browse 和 thumbnail。
2. 将每个版本分别发送至私有存储频道。
3. 在 `待入库` 中关联目标作品或图片内容单元。
4. 为同一张图片的所有版本填写同一个逻辑资源 ID。
5. 选择正确的版本和展示范围。
6. 使用排序序号确定图片页序。
7. 回到作品编排核对并将正确版本设为 `可用`。

如果“待入库”为空，先确认媒体是发送到配置的私有频道，再在管理台点击“刷新列表”。Bot 加入频道之前发送的历史消息不会自动回补，需要重新发送。

漫画正文优先以 Telegram 文档方式保存，以减少图片压缩对文字清晰度的影响。

### 14.3 独立公开封面

每个已发布作品必须设置独立公开封面：

- 封面使用 browse 或 thumbnail 图片。
- 展示范围必须是公开预览。
- 封面作为作品级资源关联，不绑定正文内容单元。
- 不使用 source 图片、会员正文图片、视频或受保护媒体作为公开封面。

在待入库关联时勾选 `设为作品独立公开封面`，系统会设置正确角色和公开范围。关联完成后仍需在作品编排中确认资源状态可用。

如果图片已经关联到内容单元，且它是 `public_preview` 范围的可用 `browse` 或 `thumbnail` 版本，可在作品编排中点击“设为封面”。系统会复制为独立作品级封面资源，不改变正文资源的归属和权限。

## 15. 媒体核验与发布

媒体关联后默认处于待确认状态。管理员应检查：

- 目标作品和内容单元是否正确。
- 图片或视频类型是否匹配单元类型。
- 文件名、尺寸、大小和时长是否合理。
- 图片版本、逻辑资源 ID 和页序是否正确。
- 展示范围是公开预览还是受保护内容。
- 公开封面是否独立于受保护正文。

确认无误后点击 `设为可用`。再将目录和内容单元设为发布，最后点击 `审核并发布`。

发布校验至少要求：

- 独立且可用的公开封面。
- 至少一个已发布目录。
- 已发布目录中存在已发布内容单元。
- 已发布内容单元拥有可用媒体。

校验未通过时，管理台会显示问题及路径。按提示补齐后重新发布，不要通过修改数据库绕过校验。

## 16. 下架与内容更新

### 16.1 更新已发布作品

1. 打开作品编排。
2. 修改资料，或新增目录、单元和媒体。
3. 核验新增资源并设置发布状态。
4. 再次执行 `审核并发布`。
5. 到用户端进行回归检查。

### 16.2 下架作品

在作品编排底部点击 `下架作品`。下架后作品不再进入用户目录。已发送到用户私聊的视频消息不会由系统自动删除。

如果只需隐藏部分内容，可将对应目录或内容单元转为草稿，再重新审核发布作品。

## 17. 用户与会员管理

1. 进入 `用户与会员`。
2. 找到目标 Telegram 用户。
3. 设置会员是否有效。
4. 按需要设置会员到期时间。
5. 保存后确认界面提示成功。
6. 在审计日志中确认会员变更记录。

有效会员可浏览全部已发布内容。普通用户在会员权限开启时不能访问会员文件，但仍可看到用于会员引导的安全基础资料和会员标识。

## 18. 系统设置与审计日志

### 18.1 系统设置

`系统设置` 当前提供：

- 会员权限总开关。
- 当前推荐算法版本信息。
- 会员引导配置摘要。

切换会员总开关会影响全部已发布内容的权限计算，操作前应确认业务意图，操作后应使用普通账号和会员账号分别检查。

### 18.2 审计日志

`审计日志` 用于查询：

- 操作动作。
- 目标类型和目标 ID。
- 管理员。
- 请求追踪号。
- IP 地址。
- 操作时间。

排查发布或权限问题时，应记录请求追踪号，便于关联服务日志。

## 19. 管理员日常检查

建议每次发布前后完成以下检查：

- `待入库` 是否有长期未处理或失败资源。
- 作品是否存在独立公开封面。
- 目录和内容单元是否处于预期发布状态。
- 媒体是否已核验并设为可用。
- 普通用户是否只能看到允许公开的内容。
- 会员是否可以读取全部已发布内容。
- 视频是否成功发送到 Bot 私聊并能使用原生播放器打开。
- 图片和漫画是否按预期顺序显示，单张失败是否可重试。
- 审计日志是否存在发布、下架或会员变更记录。

## 20. 管理员常见问题

### 20.1 上传后未出现在待入库

确认媒体发送到正确的私有存储频道，Bot 仍是频道管理员，并确认该消息是在 Bot 加入频道之后发送。必要时重新发送该媒体消息进行登记。

### 20.2 用户端看不到目录

依次检查作品、目录和内容单元的发布状态，确认单元至少有一个可用媒体，并确认测试账号具有访问权限。

### 20.3 发布提示缺少封面

在待入库中将独立的 browse 或 thumbnail 图片作为作品级公开封面关联，确认其展示范围为公开预览，并将资源设为可用。

### 20.4 图片无法发布或显示

检查 MIME、大小、尺寸、宽高比、browse 版本、逻辑资源 ID、排序和 Telegram 文件是否仍可读取。不要把 source 版本直接作为用户浏览图。

### 20.5 视频发送失败

检查用户是否启动或屏蔽 Bot、会员权限、作品和单元发布状态、视频状态、存储频道源消息、Telegram 返回原因及发送任务状态。

### 20.6 管理台无法登录

从 Bot 的 `/admin` 入口重新打开，确认当前 Telegram 账号仍在有效管理员白名单内。管理台不支持通过普通浏览器直接登录。

管理会话默认可连续使用 2 小时。页面会在会话意外失效时自动重新验证一次；如果管理页面已经打开超过 2 小时或仍提示身份验证失败，请关闭旧页面并从 Bot 的 `/admin` 入口重新打开。

## 21. 安全注意事项

- 不在前端、操作文档、截图或公开仓库中记录 Bot Token、服务器密码、数据库密码等凭据。
- 私有存储频道保持私有，并限制管理员数量。
- 不把存储频道的源消息直接转发给用户；视频始终通过受保护发送流程下发。
- 不向用户发送图片 source 文件、原图包或私有频道邀请链接。
- 不使用受保护正文作为公开封面。
- 管理员离职或账号变更时，立即停用其管理员账号并复核频道权限。
- Telegram 内容保护用于限制官方客户端中的转发和保存，不等同于 DRM，无法完全阻止录屏或设备层采集。
- 故障反馈应提供发生时间、用户操作、作品和单元名称、界面错误信息、发送状态及请求追踪号；不要在群聊中发送密钥或密码。
